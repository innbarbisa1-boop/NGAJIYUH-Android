# NGAJIYUH Android — GitHub Ready

This project wraps the existing NGAJIYUH Google Apps Script Web App in an Android WebView.

After uploading to GitHub, every push to `main` builds a debug APK automatically through GitHub Actions. You can also start it manually from Actions > Build NGAJIYUH APK > Run workflow.

APK artifact: `NGAJIYUH-APK`.

The APK is for private installation/testing. A Play Store release needs a private release signing key.
